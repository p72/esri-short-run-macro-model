# 原論文と数値処理の追加監査（2026-09-28）

対象は `ca4b0a6`（初回照合は `1ef3dbe`、再開時に最新mainへ追随） の実装と、内閣府公開の [ESRI Research Note No.72](https://www.esri.cao.go.jp/jp/esri/archive/e_rnote/e_rnote080/e_rnote072.pdf)（2022年12月）。

## 結論

付属資料IIIの152式をコードと照合した範囲では、本体の方程式に、既に説明されている誤植修正・式129の変更以外の転記誤りは確認しなかった。ただし、既定の計算は論文の式をそのまま動かす仕様ではない。式129のDLOG化には最新mainで推定統計量を使った補助実験が加わったが、それでも誤植の確証とは区別すべきである。11本の誤差修正項の固定は公表乗数への一致から選択した再現上の仮定であり、ESRIの非公開実装との同一性は確認できない。

通常の計算は再現できたが、数値異常を正常終了とする不具合と、論文忠実性の実験に誤りがあった。以下を修正した。本体の経済方程式や既定の仮定は変更していない。

## 修正した問題

| 問題 | 修正と確認 |
|---|---|
| `max(worst, NaN)` が `worst` を返し、欠損を収束と誤認する。`max(0.001, NaN)` も下限を返して欠損を隠す | 入力参照・右辺・逆変換・初期値・固定値の非有限値を検出し、期間・変数を含む例外で停止。初期値欠損からの自動補完は行わない |
| ラグの負インデックスが末尾を参照する。四半期の欠落や並び替えでも「1行前」を「1期前」として計算する | 四半期軸の連続性と参照範囲を検証。必要なラグ・リード不足を明示的に拒否 |
| 誤差項 `af` を行位置で読み、行順が違うと別の四半期の誤差項を使う | 四半期ラベルで整列し、必要な期の欠損を拒否 |
| `simulate.py` が失敗したシナリオを除外し、不完全な結果を正常終了で保存する | シナリオ失敗時は保存前に例外で停止。途中の結果を保存しないことをテスト |
| 式134の「印刷どおり」実験が主項とダミー項の両方の分母を加算へ変更する | 論文本文pp.66–67（PDF pp.68–69）を画像でも確認。誤植があるのはダミー項だけ。主項は乗算へ戻し、ダミー0/1の直接計算と照合 |
| 係数のない恒等式が実装から欠落しても、空集合どうしの比較で転記検査に合格する | 論文・実装とも式番号1〜152の存在を必須にする。成功メッセージにも絶対値集合検査の限界を明記 |

実験の設定辞書から `__itr__` を削除していた副作用も除去した。

式134の実験を修正すると、一致率は旧評価96.0%から96.2%、全変数MAEは0.0236902から0.0232977となる。既定は0.0232961。これは監査用の変種の訂正であり、既定シミュレーションの修正ではない。

## 検証

- `python src/fetch_paper.py` と `python src/check_transcription.py`：原論文を取得、152式の絶対値集合が一致。
- 付属資料IIIの式構造、ラグ・リード、移動和、差分、税率・ストックの換算、式129の両モード、付属資料Iの標準解とショックの説明を照合。曖昧な式と既存の誤植判断は `fidelity.md` の扱いを維持。
- `python -m unittest discover -s tests -v`：14テスト。異常系、手計算できる連立方程式、全152式の左辺変換と逆変換（式129の両モード）、全11シナリオの終了後の方程式残差、CLIの失敗時動作を検証。
- 既定の11シナリオ：最新mainに同梱の結果と修正後の8,910行の出力は小数第8位の保存値まで一致。標準解と実績の主要変数の最大相対差は約 `4.4e-15`。全シナリオの終了後の各方程式について、水準に戻した残差を `1+abs(値)` で割った値は `1e-8` 未満。
- 論文から再抽出した8,895行は同梱の `published_multipliers.csv` と一致。年平均の比較対象は1,779件、±0.1以内は1,711件（96.2%）。論文のシナリオ(6) `TCIV` の `#REF!` は比較不能のため除外される。
- `python src/experiment_fidelity.py`：10変種×11シナリオを再計算。印刷どおりモード（既存の誤植修正を残す）は84.1%で、既定との差を再確認。
- `ESRI_VINTAGE=2024 python src/simulate.py --start 2022Q1 --end 2024Q4`：11シナリオ完走。同梱結果との最大差 `1.0e-8`（保存桁の範囲）。
- `python src/ledger.py`：234変数の台帳検査を通過。

## 残る限界

係数の絶対値集合の一致や、誤差項を逆算した標準解の一致だけでは、方程式の正しさを証明できない。96.2%も、公表表への適合度であり、独立した予測精度の指標ではない。既存の資本コスト `UCC` の符号の不一致、所得実効税率の解釈、代用系列・一定値・逆算値の選択は未解決または仮定のまま残る。

この監査は方程式・数値ソルバー・公表11シナリオを中心にしたもの。原統計すべての再取得や季節調整の独立再現、追加の食料品減税・低所得世帯向け給付のモデル外仮定の妥当性までは検証していない。全用途でバグがないことを保証するものではない。

式129の新しい補助実験についても留意点がある。`experiment_itr_form.fit()` の決定係数は通常のR²だが、原論文のRSQは自由度修正済み決定係数である。また、仮定したGDPギャップ過程と誤差でのモンテカルロ結果は、原推定データによる再推定や著者確認の代替にはならない。これは追加検討事項としてIssueに記録する。
