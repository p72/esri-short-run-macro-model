# 消費税を減税すると、法人税収は増える？ 内閣府モデルで計算してみた

## はじめに

消費税減税の議論では、「財源はどうするのか」がいつも問題になります。

そのとき、「減税で景気が良くなれば、ほかの税収が増えて一部は戻ってくる」という意見があります。では、どの税がどれだけ増えるのでしょうか。

今回は、内閣府の「短期日本経済マクロ計量モデル（2022年版）」を Python で再現したものを使って、**名目GDPの1%規模（約5.5〜6兆円）の消費税減税**で、法人税収を中心に税収がどう変わるかを計算しました。比較のために、**同じ金額の給付金**（モデルでは個人所得税の減税として与えます）も計算しています。

結論を先に書きます。

- **消費税を減税すると、法人税収は増えます**。2年目以降は年 +0.8〜1.2兆円、ふつうより約3%多くなります。
- 理由は、減税分の約半分が値下げに回らず、**企業の取り分**になるためです。そこに消費の増加が加わり、企業の所得が約3%増えます。
- 税収の自然増で戻ってくるのは、減税額の**約15〜16%**です。同じ金額の給付金（約9%）より多いですが、**8割以上は戻ってきません**。

---

## 1. 計算の設定

- 消費税率を、事前の税収減が名目GDPの1%になるだけ引き下げます。
  - 2018〜20年の経済で計算する場合（論文と同じ版）：2.21%pt 下げる
  - 2022〜24年の経済で計算する場合（最新の版）：2.27%pt 下げる
- 減税は恒久的に続けます。
- 比較として、同じ金額の給付金（個人所得税の減税）も計算しました。

モデルでの法人税収は、「実効税率 × 前の1年間の企業の所得」で決まります。そのため、企業の所得が増えると、**1年ほど遅れて**法人税収が増えます。

---

## 2. 結果：法人税収は年0.6〜0.8兆円増える

![名目GDP1%規模の消費税減税で、法人税収はどうなるか](../output/ctax_revenue.png)

左の図は、法人税収の増え方です。

- 消費税減税（青）では、実施から1年ほどで法人税収が年0.9〜1.4兆円まで増え、その後も年0.8〜1.1兆円の増加が続きます。
- 同じ金額の給付金（オレンジ）では、年0.3兆円ほどの増加にとどまります。
- 実施直後に少し減っているのは、減税前の「買い控え」で企業の所得が一時的に減った分です。

主な数値をまとめると、次のとおりです（3年間の平均）。

![税収への影響](../output/ctax_revenue_table.png)

- **法人税収**：消費税減税で +0.61〜0.80兆円、給付金で +0.22〜0.25兆円。消費税減税の方が約3倍多く増えます。
- **企業の所得**：消費税減税で +3.2%、給付金で +0.7〜0.8%。
- **税収の合計**：消費税減税で −4.6〜5.2兆円、給付金で −5.0〜5.5兆円。
- **財源の戻り**（税収の自然増 ÷ 減税額）：消費税減税で 15〜16%、給付金で 9%。

---

## 3. なぜ消費税減税で法人税収が増えるのか

ポイントは、**減税分がどれだけ値下げに回るか**です。

このモデルでは、消費税率が変わったとき、その約半分（0.52）しか消費者が払う価格に反映されません。残りの約半分は、企業の取り分（利益）になります。

1. 消費税が下がる。
2. 値下げは約半分。残りの約半分は企業の利益になる。
3. 値下げで消費が増え、企業の売上も増える。
4. 企業の所得が約3%増える。
5. 1年ほど遅れて、法人税収が増える。

給付金の場合は、家計の手取りが増えて消費が増えるだけなので、企業の所得の増え方は小さくなります。

---

## 4. 注意点

- **「半分が企業の取り分」は、モデルの前提です**。この0.52という数字は、1990年代〜2020年のデフレ期のデータで推定されたものです。
  - 減税分がすべて値下げに回る場合は、企業の所得の増え方も、法人税収の増え方も小さくなります。
  - 前々回の記事（[円安の物価押し上げ効果](note_fx_passthrough.md)）では、最近は「コストの変化が価格に回りやすくなっている」という結果でした。今の日本では、法人税収の戻りはこの計算より小さいかもしれません。
- **ここでいう法人税収は、国の「法人税」より範囲が広い**です。法人住民税や法人事業税（所得にかかる部分）を含む、国と地方の合計です（国民経済計算の定義）。決算で見る法人税収とは一致しません。
- **財源の8割以上は戻ってきません**。税収の自然増だけで減税を賄うことはできず、財政収支は悪化します。

---

## まとめ

- 消費税を名目GDPの1%分減税すると、法人税収は年0.6〜0.8兆円（3年平均）増えます。
- 理由は、減税分の約半分が企業の利益になり、さらに消費の増加が加わって、企業の所得が増えるためです。
- 税収の自然増で戻ってくるのは減税額の約15〜16%で、同じ金額の給付金（約9%）より大きいものの、大部分は戻りません。

「消費税減税は企業を潤す」という見方は、このモデルでは数字として確認できます。ただし、それは「減税分が全部は値下げに回らない」ことの裏返しでもあります。家計にとっての恩恵と、法人税収の戻りは、どちらかが大きければもう一方が小さくなる関係にある点に注意が必要です。

### 計算の詳細

- コード・データ：GitHub リポジトリ（内閣府 ESRI 短期日本経済マクロ計量モデル 2022年版の Python 再現）
  - 計算：`src/experiment_ctax_revenue.py`
  - 図・表：`src/plot_ctax_revenue.py`
- モデルのデータ：内閣府 国民経済計算などから作成
  - 論文と同じ版：2021年10-12月期2次速報・2020年度年次推計、2015年基準

- 法人税収：国民経済計算の一般政府の「所得・富等に課される経常税」（受取）から、家計の支払分を引いた値
