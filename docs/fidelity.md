# 論文への忠実性の監査

対象: ESRI Research Note No.72「短期日本経済マクロ計量モデル(2022年版)の構造と乗数分析」付属資料III（方程式体系、152本）と `src/model.py`。
目的: 実装が論文の印刷どおりか、どこをどう変えたか、変えた根拠は何か、印刷どおりに戻すと乗数がどう変わるかを、すべて再現可能な形で示す。

再現手順:

```bash
python src/fetch_paper.py            # 論文PDF → reference/rn72_2022model.txt
python src/check_transcription.py    # 係数・定数の機械照合（152本）
python src/experiment_fidelity.py    # 印刷どおり・別解釈・修正前の式で11シナリオを解く → output/experiment_fidelity.csv
python src/experiment_ecm_greedy.py  # 誤差修正項の固定の探索 → output/experiment_ecm_{freeze_one,greedy,nested}.csv
python src/simulate.py --itr level --ecm live   # 印刷どおりモード（出力に _ecmlive_itrlevel が付く）
```

一致度の指標は、論文の乗数表（54変数 × 11シナリオ × 3年）に対する「±0.1以内の割合」と平均絶対誤差（MAE）。既定の実装は 96.2% / 0.0233。

## 1. 結論

| 項目 | 評価 |
|---|---|
| 係数・定数の転記 | **152本すべて一致**（`check_transcription.py` で機械照合） |
| 式の構造（ラグ、差分、対数、移動和、ダミー） | 目視で152本を照合し、印刷と一致。誤植と判断して直した箇所が7件（§3） |
| 読み方が分かれる印刷 | 4件を両方の読み方で解き、論文の乗数表に合う読み方を採用（§4） |
| 印刷された式からの意図的な逸脱 | **2件**: 式129 の型（§5.1）と誤差修正項の固定（§5.2）。どちらも切り替え可能で、印刷どおりに戻すと一致率は 96.2% → 84.1% |
| 式以外の判断 | 解く期間・シナリオの実装・データの代用は README と `data/processed/variable_ledger.csv` に記載（§6） |

つまり、**方程式の転記は忠実**で、**乗数表を再現するために印刷と違う扱いをしている点は2つ**に絞られる。2つとも「印刷どおり」と「既定」を同じコードで切り替えられる。

## 2. 転記の照合

`src/check_transcription.py` は論文テキストを式番号ごとに分け、各式に現れる数値リテラル（係数・定数。t値、決定係数、変数名中の数字、100 や 400 などの単位換算定数は除く）の集合を `model.py` の同じ式の集合と比べる。結果は 152/152 で一致。

構造は目視で照合した。特に注意した点:

- `@MOVSUM(X, i)` は当期を含む i 期の移動和として実装（EViews の定義）。式4・9・85・91・116・130・131 で使用。
- `DLOG(x, 0, 4)`（式9）は EViews の `D(LOG(x), 0, 4)` = 前年同期比の対数差として実装。
- リード項 `D(JA_RTCI(1))`, `D(JA_RTCI(2))`（式3・5）は先の期の値を参照する。このため解く期間を 2017Q3 から始める（README）。
- `MAX(0.001, x)`（式113・115）は下限の切り上げ。
- 式116 の `D(DLOG(JA_PCPAT(-1)*400))` は定数倍が対数差で消えるので、印刷どおりなら `DLOG(PCPAT(-1))` の階差に等しい（§4）。

## 5. 印刷された式からの意図的な逸脱

### 5.1 式129 所得実効税率の型（Issue #2）

印刷は `LOG(ITR/ITREQ) = -0.958520·LOG(ITR(-1)/ITREQ) + 0.625328·GDPGAP/100`（水準式）。既定はこれを `DLOG(ITR/ITREQ) = …`（左辺を階差、右辺の `ITREQ` を1期ラグ）と読み替えている。

| 指標 | 印刷どおり（水準式） | 既定（DLOG型） | 論文 |
|---|---:|---:|---:|
| ±0.1以内の割合 | 95.3% | 96.2% | — |
| 実質GDP 年乗数の MAE | **0.0087** | 0.0098 | — |
| 個人所得税 `TYPV` の MAE | 0.176 | 0.060 | — |
| シナリオ(1) `TYPV` 2018/19/20年 | 0.89 / 1.54 / 1.65 | 1.20 / 1.85 / 1.90 | 1.20 / 1.89 / 1.99 |

読み替えの根拠は個人所得税の四半期経路だけで、実質GDPの一致は印刷どおりのほうが僅かに良い。水準式のままだと、公共投資シナリオで GDP ギャップが開いても税率が2期で元に戻る（係数 −0.9585 ≈ −1）ため、税収の反応が論文の半分強になる。印刷どおりで解くには `python src/simulate.py --itr level`。正誤表・元資料での確認は Issue #2 で継続。

### 5.2 誤差修正項の固定

印刷どおりに14本の誤差修正項（長期均衡からの乖離に係数を掛けた項）をすべて動かすと 85.2%、`IHP`（住宅投資）の MAE が +0.52 悪化する。既定は `CP`・`PCPAT`・`YICV` の3本だけ動かし、他の11本は標準解の値で固定する（`src/ecm.py`）。

根拠（`experiment_ecm_greedy.py`）:

1. **全有効から1本ずつ固定**（`experiment_ecm_freeze_one.csv`）: 固定して改善するのは IHP（MAE 0.0683→0.0487）、XGS、PNFMGSAT、LHX、PFUELAT、PLAND、PIFPAT、CGPIAT、YWV、FUEL の10本。固定して悪化するのは YICV（→0.0717）、PXGS、PCPAT、CP。
2. **貪欲法**（`experiment_ecm_greedy.csv`）: 最も改善する項から順に固定すると、IHP → XGS → LHX → FUEL → PFUELAT → PLAND → PXGS → PNFMGSAT → PIFPAT → CGPIAT → YWV の順に単調に改善し、`CP`・`PCPAT`・`YICV` の3本が残ったところで止まる。以前の切り分け（`experiment_ecm_ablation.py`、`experiment_ecm_combo.py`）と同じ組に、逆方向の探索でも到達する。
3. **印刷の形との対応**: 固定して改善する式は、論文で長期均衡を `LOG(x(-1)) − ( … 定数 )` の入れ子括弧で書いている（IHP, XGS, FUEL, LHX, CGPIAT, PIFPAT, PFUELAT, PNFMGSAT, PLAND）。動かすべき3本（CP, PCPAT, YICV）は入れ子なしで書かれている。2段階で推定した長期均衡の残差を外生の系列としてモデルに入れると、シミュレーションで誤差修正項が動かず、この結果になる。ESRI のモデルファイルは公開されていないため確認はできない。
4. 同じ入れ子形で `ecm.py` の対象にしていない NFMGS・PCGAT・PIGAT（係数 −0.0004〜−0.013）は、固定しても結果が変わらない（`experiment_ecm_nested.csv`、差は MAE 0.0001 以内）。
5. `YWV`（式89）は入れ子なし・長期均衡が定数 `BETA` だけだが、固定すると僅かに良い（96.2% vs 有効 96.0%）。3 の説明と合わないので判定保留とし、既定は固定のまま。

印刷どおりで解くには `python src/simulate.py --ecm live`。

## 6. 式以外の実装上の判断

論文の方程式には含まれず、再現のために決めた事項。詳細は README「論文から読み取った判断・修正」と `data/processed/variable_ledger.csv`。

| 項目 | 内容 |
|---|---|
| 標準解 | 実績値。各式の残差（`CERR*ERTS_xx`）を実績から逆算して足し戻す |
| 解く期間 | 2017Q3〜2020Q4（式3・5の消費税率リード項のため）。表示は 2018Q1〜 |
| シナリオの実装 | (3) 名目公共投資は `IGV` を外生化して `IG` を内生化、(5) 法人税は `ETT` と `TT` を同率で引下げ、(8) 貨幣供給量は `M2CD` を外生化して式111を `RCD` について解く |
| データ | `HH`・`PLAND`・`WD_PX` など9変数が代用、`REQU` など7変数が仮定値（台帳の `status` 列） |
